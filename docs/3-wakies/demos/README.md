# Démonstrations historiques du gabarit OpenDots

Ces vidéos documentent l’ancien gabarit OpenDots, archivé lors du remplacement par OpenMuse. Elles ne représentent pas les sources actuellement présentes dans apps/wakies. Elles ne décrivent pas l’état du port mAI Web sous /wakies. Pour le statut des fonctions intégrées, consultez [INTEGRATION.md](../INTEGRATION.md).

Les captures ont été réalisées dans un projet Intelligence de démonstration et un espace Launch studio séparé. Elles n’exposent pas de données client ni d’identifiants. Les réponses montrées proviennent de sessions réelles ; elles n’ont pas été remplacées par du texte simulé.

| Vidéo | Parcours | Durée |
| --- | --- | --- |
| [Chat vers un espace](chat-to-space.mp4) | Recherche sur le Web, brouillon, approbation puis page enregistrée | 23 s |
| [Chat spécialiste](specialist-chat.mp4) | Suite d’une planification avec une réponse en direct | 13 s |
| [Espaces et pages](spaces-page-chat.mp4) | Lecture d’une page sauvegardée et conversation associée | 19 s |
| [Ordinateur](computer-chat.mp4) | Navigation, sauvegarde d’un fichier et vérification dans le terminal | 34 s |
| [Appel vocal](voice-call.mp4) | Interface d’appel WebRTC, contrôles et reçu de fin d’appel | 15 s |

Les versions GIF servent d’aperçu compact ; les MP4 sont fournis pour une lecture plus fidèle. Les séquences ont été recadrées, échantillonnées à basse fréquence et accélérées. Elles illustrent des parcours, pas la latence ni les performances d’animation.

## Portée des démonstrations

Les clips ordinateur montrent un service OpenBot dédié, avec navigateur, fichiers et terminal. Le clip de révision montre une carte d’approbation avant l’enregistrement. La démonstration d’appel est une capture silencieuse ; le microphone a été contrôlé dans une session de validation distincte. Les intégrations Slack et la délégation vocale ne sont pas démontrées ici.

Les dates et limites propres à chaque essai sont détaillées dans les sections de chaque enregistrement ci-dessous. Avant de refaire une capture, utilisez un espace de démonstration séparé, masquez les paramètres et secrets, vérifiez chaque segment et actualisez la date et la portée.
