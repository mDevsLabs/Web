# Blackline (`6-blackline`)

Blackline est un FPS 3D solo (Three.js) intégré à mAI Web sous `/blackline`.
C'est une application **légère** : pas de compte, pas de service payant, pas de
synchronisation de progression. Elle est là pour le temps d'attente.

| Document | Contenu |
| --- | --- |
| [INTEGRATION.md](INTEGRATION.md) | Architecture, montage, feuille de style, réglages, build |
| [AGENTS.md](AGENTS.md) | Règles impératives pour les agents et les contributeurs |

## En une phrase

Le jeu est un artefact statique produit par Vite, monté par l'hôte dans une
page `/blackline`, dont les réglages sont partagés par compte et dont l'accès
est conditionné à une confirmation d'âge PEGI 16 demandée à chaque lancement.
